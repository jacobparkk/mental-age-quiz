# Mindprint — Mental Age Quiz

Mindprint is a polished, entertainment-focused personality quiz built with React, TypeScript, Vite, and Framer Motion.

## Improvements

- 12 scenario-based questions with five nuanced choices each
- Weighted mental-age calculation instead of category counting
- Four-dimensional personality profile: curiosity, stability, sociability, and reflection
- Deterministic results without object-order tie bias
- Answer navigation, animated transitions, responsive design, and persistent light/dark mode
- Rich result narrative, share support, and clear non-clinical disclaimer

Run `npm install` followed by `npm run dev`. Use `npm run build` for a production build.
